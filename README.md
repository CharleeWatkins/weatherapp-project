## WeatherApp
Weather app built with React, TypeScript, and Vite. It pulls live conditions from Open-Meteo, alerts from WeatherAPI, and saves your settings locally. Services Used: Open-Meteo (Weather and Search), BigDataCloud (Location), and WeatherAPI (Alerts—requires a free API key with 7 day trail).
